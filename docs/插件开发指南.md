# 插件开发指南

用 Python 写一个插件，就能让「阅读」做它内置能力之外的事：**把 TXT 清洗成规范电子书**、
**从公开来源抓取内容并生成电子书**。插件在应用里导入、启用后即可运行，产物直接进书架。

- 语言：Python 3，可用标准库；应用预置 `requests`、`charset-normalizer`、`epub-generator`。
- 载体：一个 `.py` 文件（单文件即可，也可以自己拆模块放进同一个文件里）。
- 产物：**EPUB 3**，应用会用内置解析器读回（书名、作者、目录、正文、封面）。

---

## 一、在应用里用插件

1. 设置 → 脚本插件 → 右上角「导入 .py」（或菜单里「导入内置示例」）。
2. 在列表里打开开关启用脚本；点 ▶ 运行。
3. 运行页会实时显示你 `print()` 出来的日志，运行中可以随时取消。
4. 成功后点「导入产物」，生成的书会进书架（也可以在书架里直接打开）。

---

## 二、快速开始

插件通过**文件**与「阅读」交换数据，全部使用相对路径：

```python
# 我的第一个插件：把输入原样包成一本电子书
import json, os

params = json.load(open("params.json", encoding="utf-8"))     # 任务参数
src = os.path.join("input", params["input_file"])              # 输入文件
text = open(src, encoding="utf-8").read()

print(f"读到 {len(text)} 字")                                   # 会出现在运行日志里

os.makedirs("output", exist_ok=True)                            # 产物目录
open("output/book.epub", "wb").write(build_epub(text))          # 见第四节
```

要点：

- `params.json`：应用写入的参数，脚本自己读。**缺失字段请给默认值**。
- `input/`：输入文件；`output/`：你的产物。其它路径不要写死。
- 用 `print()` 输出进度；运行日志就是给作者和用户看的。

---

## 三、参数与结果

### 3.1 params.json（读）

| 字段 | 说明 |
|---|---|
| `task` | `clean`（清洗文本）或 `source`（抓取书源） |
| `input_file` | `input/` 下的输入文件名（`clean` 任务） |
| `output_file` | 期望的产物名，写进 `output/` |
| `title` / `author` | 可选元数据 |

`source` 任务的参数由你在插件页面里填写（JSON 形式），应用原样传给插件，
例如 `urls`、`cookies`、`headers`、`max_pages` 等，随你设计。

### 3.2 结果

插件**不需要**自己写任何结果文件：正常结束即为成功；
抛异常会被记录并回传（运行页会显示错误与保留的现场）。产物放在 `output/` 即可。

所以插件的写法就是普通的 Python 脚本：读参数 → 干活 → 把 EPUB 写进 `output/`。

## 四、生成 EPUB 3

### 方式一：`epub-generator`（已预置）

```python
from epub_generator import EpubGenerator  # 包名以官方文档为准

gen.add_chapter("第一章 夜叩门", "<p>夜色像一层薄薄的墨。</p>")
gen.save("output/book.epub")
```

### 方式二：只用标准库（零依赖，可控）

```python
import zipfile

def build_epub(chapters, title="未命名", author="佚名", path="output/book.epub"):
    opf = f"""<?xml version="1.0" encoding="utf-8"?>
<package xmlns="http://www.idpf.org/2007/opf" version="3.0" unique-identifier="id">
  <metadata xmlns:dc="http://purl.org/dc/elements/1.1/">
    <dc:identifier id="id">my-plugin</dc:identifier>
    <dc:title>{title}</dc:title><dc:creator>{author}</dc:creator>
    <dc:language>zh-CN</dc:language>
  </metadata>
  <manifest>
    <item id="nav" href="nav.xhtml" media-type="application/xhtml+xml" properties="nav"/>
""" + "".join(
        f'<item id="c{i}" href="c{i}.xhtml" media-type="application/xhtml+xml"/>'
        for i in range(1, len(chapters) + 1)
    ) + """
  </manifest>
  <spine>""" + "".join(
        f'<itemref idref="c{i}"/>' for i in range(1, len(chapters) + 1)
    ) + """</spine>
</package>"""
    with zipfile.ZipFile(path, "w") as z:
        # mimetype 必须是第一个条目，且不压缩
        z.writestr(zipfile.ZipInfo("mimetype"), "application/epub+zip",
                   compress_type=zipfile.ZIP_STORED)
        z.writestr("META-INF/container.xml",
                   '<?xml version="1.0"?><container version="1.0" '
                   'xmlns="urn:oasis:names:tc:opendocument:xmlns:container">'
                   '<rootfiles><rootfile full-path="OEBPS/content.opf" '
                   'media-type="application/oebps-package+xml"/></rootfiles></container>')
        z.writestr("OEBPS/content.opf", opf)
        z.writestr("OEBPS/nav.xhtml", nav_xhtml(chapters))
        for i, (t, body) in enumerate(chapters, 1):
            z.writestr(f"OEBPS/c{i}.xhtml", chapter_xhtml(t, body))
```

**两条硬性要求**：

1. `mimetype` 是压缩包里的**第一个**条目，且**不压缩**（`ZIP_STORED`）；
2. 有 `META-INF/container.xml` 指向 OPF，OPF 里 `manifest`/`spine` 完整。

标题用 `<h2>`、正文用 `<p>`，应用读取时就能正确识别章节与正文。

## 五、网络通讯示例（抓取书源）

```python
import json, time, requests

params = json.load(open("params.json", encoding="utf-8"))
session = requests.Session()
session.headers.update({
    "User-Agent": "Mozilla/5.0 (Linux; Android 14) AppleWebKit/537.36 Chrome/120 Safari/537.36",
    "Accept-Language": "zh-CN,zh;q=0.9",
})
if params.get("cookies"):
    session.cookies.update(params["cookies"])

def fetch(url, retries=3):
    for attempt in range(1, retries + 1):
        try:
            resp = session.get(url, timeout=(5, 20))     # 连接/读取都要设超时
            resp.raise_for_status()
            resp.encoding = resp.apparent_encoding or "utf-8"
            return resp.text
        except Exception as error:
            print(f"第 {attempt} 次失败：{error}")
            if attempt == retries:
                raise
            time.sleep(1.5 * attempt)                    # 退避重试，别把站点打挂

# 分页抓取
chapters = []
for page in range(1, int(params.get("max_pages", 3)) + 1):
    html = fetch(f"{params['urls'][0]}?page={page}")
    print(f"第 {page} 页：{len(html)} 字节")
    chapters.extend(parse(html))          # 你的解析逻辑：用 html.parser / 正则 / bs4

build_epub(chapters)                      # 复用第四节的 EPUB 生成
```

建议：

- 显式 `timeout`；失败重试并退避；不要并发几十个请求。
- 尊重站点条款与 `robots.txt`，控制频率；只抓取可公开获取的内容。
- 需要登录态时，把 Cookie 通过插件参数（JSON）传入，不要硬编码在代码里。
- 文本编码不确定时：`charset-normalizer` 探测后解码，或 `resp.apparent_encoding`。
- 结构化数据（JSON 接口）优先于解析 HTML，更稳也更省流量。

## 六、TXT 清洗建议

- **编码**：先 `rb` 读字节，用 `charset-normalizer` 或 `utf-8 → gb18030` 顺序试探。
- **清理**：用 `re.sub(pattern, repl, text, flags=re.MULTILINE)` 逐条规则处理，
  规则可以放在插件参数里（`clean_rules`），方便不改代码调整。
- **分章**：用章节标题的正则切分，例如 `^第[一二三四五六七八九十百千0-9]+章.*$`；
  找不到标题时整本当作一章，不要报错。
- **段落**：按行处理，去掉首尾空白；空行不要写进 EPUB。
- 内置示例 `python/examples/txt_cleaner.py` 覆盖了以上全部要点，可以直接改。

---

## 七、编码与跨平台注意事项

| 事项 | 建议 |
|---|---|
| 文件编码 | 所有 `open()` 显式 `encoding="utf-8"`；读入文本先探测再解码 |
| 换行 | 统一按 `\n` 处理，写出时可用 `newline="\n"` |
| 路径拼接 | 用 `pathlib.Path("output") / "book.epub"`，不要手拼分隔符 |
| 临时文件 | 放 `work/` 目录，随便用，运行结束会一起清理 |
| 大小写 | 文件名、目录名全小写（部分平台区分大小写） |
| 不要用 | `subprocess`、`multiprocessing`（移动端不可用）；需要并发用线程 |
| 浮点数 | 签名/哈希场景全程用整数与字节串 |

## 八、调试

- `print()` 的内容会实时出现在运行页的日志里；建议在每个阶段打一行（收到多少字节、
  解析出多少章、写出了哪个文件）。
- 出错时异常信息会显示在页面上，**现场会保留**（页面给出目录路径），可以查看中间产物。
- 运行中可以点「取消」；取消后不保留产物。
- 插件写得越"幂等"越好：同一个输入跑两次结果一致，便于重试。

---

## 九、常见问题

| 现象 | 处理 |
|---|---|
| 运行页显示失败但没细节 | 在容易出错的步骤前后加 `print()`，并 `raise` 出原始异常 |
| 中文乱码 | 检查是否显式指定编码；用 `charset-normalizer` 探测 |
| 产物导入后没有目录 | EPUB 缺少 `properties="nav"` 的导航文档 |
| 书架里书名是文件名 | EPUB 的 `dc:title` 没写或为空 |
| 运行很久没动静 | 检查网络 `timeout` 与重试次数；必要时在页面取消后重跑 |
| 下载被拒绝 | 补 User-Agent/Referer，降低频率；确认内容可公开获取 |

## 十、合规提醒

插件机制只提供运行环境与文件约定。请自行确保：抓取的内容可公开获取、遵守目标站点的
服务条款与 `robots.txt`、不侵犯版权，不绕过任何技术保护措施。应用不内置也不分发
任何针对特定站点的抓取脚本。
