# 插件开发指南（纯 Dart 插件体系）

ReaderPlus 的插件是**纯 Dart** 实现的：脚本用 [Hetu Script](https://pub.dev/packages/hetu_script)，
书源也可以写成**声明式规则**（JSON）。两者由同一个执行器运行 —— 同一个 isolate、
同一套宿主能力、同样的超时与取消语义。

> 历史说明：早期版本用 Python（serious_python）跑插件，已完全移除。
> 旧 Python 脚本**不兼容**，请按本指南重写（格式更简单：不需要 `SCRIPT` 声明、
> 不需要 params.json/manifest.json，直接调用下面的能力函数即可）。

## 一、为什么是纯 Dart

| 事项 | 说明 |
|---|---|
| 多端一致 | 脚本引擎与宿主能力都是 Dart 代码，Android / Linux 行为完全一致，没有按平台分发二进制的问题 |
| 崩溃隔离 | 脚本在**独立 isolate** 里执行；`while(true){}` 会被硬超时 `Isolate.kill` 掉，应用毫发无损 |
| 真取消 | 到点即杀 isolate，不是"标记一下稍后处理" |
| 沙盒 | 脚本**只能**调用下面列出的宿主函数：没有文件系统、没有裸网络、没有进程能力 |
| 实时日志 | `log()` 逐条回调到界面（不显示进度条） |

## 二、快速开始

脚本就是一段 Hetu 代码。最小示例（把输入文本原样存成产物）：

```hetu
var text = inputText('raw.txt')
log("输入 ${text.length} 字符")
saveOutput('out.txt', text)
result('ok')
```

放置与使用：**书源页 → 右上角 + → 选择 `.ht` 文件**（或 `.json` 规则文件），
之后勾选它并搜索即可。内置示例随应用打包，首次进入自动写入：
`内置：TXT 清洗转 EPUB`、`内置：本地测试书源`。

## 三、脚本类型声明（必须写，避免被错用）

每个脚本**头部**都要声明自己的类型（纯 Dart 静态解析，不执行代码）：

```hetu
// @script kind=source name="我的书源"
```

| kind | 含义 | 出现位置 |
|---|---|---|
| `source` | 书源（搜索/详情/下载） | 「书源」页 |
| `clean` | 清洗（TXT → EPUB） | 「脚本管理」清洗分类 |
| `tool` | 其它工具脚本（**默认值**） | 「脚本管理」其他分类 |

- 支持多行续写：`// @script kind=clean` 后面跟 `// name="…"`、`// capabilities=…`；
- `name` 会作为显示名（可选）；
- **不写声明、或写了未知类型 = tool**：最保守的默认，**不会被当成书源误用**。

管理入口：**设置 → 脚本管理**，可按类型分组查看、编辑、删除、从模板新建。
编辑保存后会重新解析声明，类型随之更新。

## 三、脚本语言（Hetu）必读约定

这些约定都是踩过坑总结的，写脚本时按它来：

1. **字符串拼接**：字符串与数字**不能**用 `+`。用插值：`log("共 ${n} 条")`。
2. **异步**：宿主函数返回 Dart `Future`，用 `.then(callback)` 续跑；
   回调**必须用花括号函数体** —— `=> { ... }` 会被当成返回结构体的表达式，
   是本次开发中最后踩到的坑：
   ```hetu
   httpGet('https://example.com').then((response) {
     log("状态 ${response['status']}")
     result(response['text'])
   })
   ```
3. **返回值交回**：用 `result(...)`。对象字面量在 Hetu 里是**结构体**，
   引擎会自动递归转成 JSON 结构交给宿主；需要严格 JSON 文本时用内置
   `JSON.stringify(...)`。集合可用 `Map()` / 列表字面量 `[...]`。
4. **判等与成员**：`==` 判等；结构体用 `s['field']` 或 `s.field` 取值。
5. **外部函数不需要声明**：引擎会自动为下面的能力注入 `external function` 声明。

## 四、宿主能力（全部由 Dart 提供，跨端一致）

### 4.1 日志与结果

| 函数 | 说明 |
|---|---|
| `log(message)` | 写一条日志（实时显示在书源页的"执行过程"面板） |
| `result(value)` | 交回结果（最后一次生效；脚本结束前至少调用一次） |

### 4.2 参数与输入输出

| 函数 | 说明 |
|---|---|
| `param(name, fallback?)` | 读宿主参数：`task`（search/detail/download）、`query`、`id`、`page` 等 |
| `params()` | 读出全部参数 |
| `inputText(name, encoding?)` | 读输入文本（`encoding` 缺省 `auto`：先严格 UTF-8，失败再按 GBK） |
| `inputBytes(name)` | 读输入字节 |
| `saveOutput(name, bytes)` | 写产物到本次运行的产物目录，返回完整路径 |

### 4.3 HTTP（既简单，也高自由度）

| 函数 | 说明 |
|---|---|
| `httpGet(url, headers?)` | 简单 GET，返回 `{status, reason, url, headers, text}` |
| `httpPost(url, body?, contentType?, headers?)` | 简单 POST |
| `httpRequest(options)` | 高自由度请求，见下表 |

`httpRequest` 的 `options`：

| 字段 | 说明 |
|---|---|
| `url`、`method` | 必填 URL 与方法（GET/POST/PUT/DELETE/…） |
| `headers` | 多值头：`{'X-A': ['1','2']}` |
| `rawHeaderLines` | 逐行原样加头：`['X-A: 1', 'Cookie: a=b']` |
| `body` | 文本或字节数组 |
| `contentType` | 如 `application/x-www-form-urlencoded` |
| `cookies` | `{'k':'v'}`；宿主另有 cookie 罐自动收/发 |
| `connectTimeoutMs` / `idleTimeoutMs` | 超时控制 |
| `followRedirects` / `maxRedirects` | 重定向控制 |
| `proxy` | 形如 `PROXY host:port`（或 `DIRECT`） |
| `allowBadCertificate` | 是否允许自签证书（默认不允许） |

### 4.4 文本 / 编码 / 正则 / URL

| 函数 | 说明 |
|---|---|
| `decode(bytes, encoding?)` | 字节转文本（UTF-8 / GBK / Latin-1 …） |
| `regexp(pattern, input, group?)` | 首个匹配（`group` 缺省 `0`）；支持内联标志 `(?m)(?i)(?s)` |
| `regexpAll(pattern, input, group?)` | 全部匹配，返回列表 |
| `urlJoin(base, relative)` | 相对地址解析 |
| `urlEncode(value)` | URL 编码 |

### 4.5 EPUB 3 与文本处理

| 函数 | 说明 |
|---|---|
| `splitChapters(text, pattern?)` | 按标题正则分章，返回 `[{title, body}, ...]` |
| `cleanText(text, rules)` | 规则清洗：`[[正则, 替换], ...]` |
| `epubBuild(options)` | 生成 EPUB 3 字节 |

`epubBuild` 的 `options`：`{title, author, language, chapters:[{title, body}], cover:[字节], coverName}`。
产物**严格符合 EPUB 3.3**（官方 EPUBCheck 5.3.0 校验：0 fatals / 0 errors / 0 warnings / 0 infos）。

Hetu 自带能力也可用：`JSON.parse/stringify`、`Map()`、列表、`Future` 等。

## 五、完整示例一：TXT 清洗转 EPUB

```hetu
var text = inputText('raw.txt')
text = cleanText(text, [
  ['[\\u200b\\ufeff]', ''],
  ['(?m)^\\s*(广告|推广)[:：].*$', '']
])
var chapters = splitChapters(text, '^第[一二三四五六七八九十百千两0-9]+[章回节卷].*$')
log("切分得到 ${chapters.length} 章")

var options = {}
options['title'] = param('title', '未命名')
options['author'] = param('author', '佚名')
options['chapters'] = chapters
saveOutput('book.epub', epubBuild(options))
result('ok')
```

## 六、完整示例二：书源脚本（搜索 / 详情 / 下载）

一个脚本用 `param('task')` 区分三种任务：

```hetu
var task = param('task', 'search')

if (task == 'search') {
  var q = param('query', '')
  httpGet('https://gutendex.com/books?search=' + urlEncode(q)).then((r) {
    var raw = r['text']
    var parsed = regexpAll('"id":\\s*(\\d+)', raw, '1')
    var items = []
    for (var i = 0; i < parsed.length; i = i + 1) {
      var item = {}
      item['id'] = parsed[i]
      item['title'] = '待补充书名'
      items.add(item)
    }
    log("命中 ${items.length} 条")
    var payload = {}
    payload['items'] = items
    result(payload)
  })
} else if (task == 'detail') {
  var payload = {'id': param('id'), 'title': '书名', 'description': '简介'}
  result(payload)
} else {
  var payload = {'id': param('id'), 'chapters': [{'title': '第一章', 'body': '正文'}]}
  result(payload)
}
```

要点：
- 搜索必须交回 `{items: [{id, title, author, cover, intro}, ...]}`，`id` 必填；
- 详情交回 `{id, title, author, description, cover}`；
- 下载交回 `{chapters: [{title, body}, ...]}`（应用会用 EPUB 模块打包后入库）。

## 七、声明式书源（规则，JSON）

简单的书源不必写脚本。规则文件示例：

```json
{
  "id": "gutenberg",
  "name": "古腾堡（示例）",
  "version": 1,
  "search": {
    "url": "https://gutendex.com/books?search={{query}}&page={{page}}",
    "format": "json",
    "list": "results[*]",
    "fields": {
      "id": "id",
      "title": "title",
      "author": "authors[0].name"
    }
  },
  "detail": {
    "url": "https://gutendex.com/books/{{id}}",
    "format": "json",
    "fields": {"title": "title", "author": "authors[0].name"},
    "description": "summaries[0]"
  },
  "download": {
    "url": "https://www.gutenberg.org/cache/epub/{{id}}/pg{{id}}.txt",
    "format": "text"
  }
}
```

| 字段 | 说明 |
|---|---|
| `url` | 支持 `{{query}}`/`{{page}}`/`{{id}}` 模板（自动 URL 编码） |
| `format` | `json` / `xml` / `text` / `html` |
| `list` | 列表选择器，如 `results[*]`（仅搜索用） |
| `fields` | 字段 → 选择器：`a.b[0].c`、`a[*]`、XML 元素名 |
| `description` / `cover` | 详情页的简介与封面选择器 |
| `chapter_pattern` | 下载时按此正则分章（缺省整本当一章） |

规则与脚本**共用同一套宿主能力**（同一条 HTTP 栈、同一隔离、同一超时取消），
因此规则也能用上多值头、代理、超时等设置（写在 `headers` 等字段里）。

## 八、调试

- 书源页的**执行过程面板**实时显示 `log()` 输出与失败原因；
- 开发者页（设置 → 关于 → 连点「版本」7 次）可看应用日志文件；
- 常见错误：
  - `字符串 + 数字` → 用插值；
  - `.then((x) => { ... })` → 改花括号函数体；
  - `result` 没被调用 → 脚本结束前必须交回结果；
  - 忘记 `param('task')` 分支 → 三种任务都要处理。
