# 插件开发指南

写一个 Python 插件，就能让「阅读」做内置能力之外的事：**把 TXT 清洗成规范电子书**、
**从公开来源抓取内容并生成电子书**。插件在应用里导入、启用后即可运行，产物直接进书架。

- 语言：Python 3，可用全部标准库。
- 预置依赖（**各平台完全一致**）：`requests`、`charset-normalizer`，
  以及内置的 EPUB 生成库 `readerplus_epub`（标准库实现，见第四节）。
- 产物：**EPUB 3**，应用会用内置解析器读回（书名、作者、目录、正文、封面）。
- 载体：一个 `.py` 文件即可。

---

## 一、在应用里使用插件

1. 设置 → 脚本插件 → 右上角「导入 .py」（或菜单「导入内置示例」）。
2. 在列表里打开开关启用插件，点 ▶ 运行。
3. 运行页实时显示你 `print()` 出来的日志，运行中可以随时取消。
4. 成功后点「导入产物」，生成的书会进书架。

---

## 二、快速开始

插件通过**文件**与「阅读」交换数据，一律使用相对路径：

```python
# 我的第一个插件：把输入原样包成一本电子书
import json, os

params = json.load(open("params.json", encoding="utf-8"))   # 任务参数
src = os.path.join("input", params["input_file"])            # 输入文件
text = open(src, encoding="utf-8").read()

print(f"读到 {len(text)} 字")                                 # 显示在运行日志里

from readerplus_epub import EpubBook
book = EpubBook(title=params.get("title", "未命名"), author="佚名")
book.add_chapter("正文", text)
book.save(os.path.join("output", params.get("output_file", "book.epub")))
```

三件事记住就够了：

- `params.json`：应用写入的参数，脚本自己读，**缺失字段给默认值**；
- `input/`：输入文件；`output/`：你的产物；
- `print()`：输出进度到运行日志。

## 三、接口契约

### 3.1 params.json（读）

| 字段 | 说明 |
|---|---|
| `task` | `clean`（清洗文本）或 `source`（抓取来源） |
| `input_file` | `input/` 下的输入文件名（`clean` 任务） |
| `output_file` | 期望的产物文件名（写进 `output/`） |
| `title` / `author` | 可选元数据 |

`source` 任务的参数由你在插件页面里以 JSON 填写（例如 `urls`、`cookies`、`headers`、
`max_pages`），应用原样传给插件，随你设计。

### 3.2 输入与输出

- 读：`input/<input_file>`，只读。
- 写：`output/` 下的文件就是最终产物（必须能被当作 EPUB 3 解析）。
- 临时文件：放 `work/`，随便用，运行结束一并清理。

### 3.3 成功与失败

- **正常结束 = 成功**；产物放在 `output/` 即可。
- **抛异常 = 失败**：异常信息会显示在运行页，现场（含中间产物）会保留，便于排查。
- 不需要自己写任何结果文件。

### 3.4 日志

`print()` 的内容实时出现在运行页。建议每个阶段打一行：收到多少字节、解析出多少章、
写出了哪个文件。

## 四、生成 EPUB 3（内置库 `readerplus_epub`）

各平台都预置了同一个纯标准库实现，API 完全一致：

```python
from readerplus_epub import EpubBook

book = EpubBook(title="夜航船", author="张岱", language="zh-CN")
book.add_chapter("第一章 夜叩门", "夜色像一层薄薄的墨，慢慢洇开在窗棂上。")   # 纯文本按行转 <p>
book.add_chapter("第二章 旧信笺", "<p>这样的夜里，适合想一些很久以前的事。</p>",
                 is_html=True)                                          # 也可以用 HTML
book.set_cover(cover_bytes, "cover.jpg")                                # 可选
book.save("output/book.epub")                                           # 目录不存在会自动创建
```

| 方法 | 说明 |
|---|---|
| `EpubBook(title, author="佚名", language="zh-CN", identifier=None)` | 创建一本书（之后按顺序加章节） |
| `add_chapter(title, body, is_html=False)` | 加一章；`body` 为纯文本时按行转 `<p>` |
| `set_cover(image_bytes, filename="cover.jpg")` | 设置封面（支持 jpg/png/gif/webp） |
| `save(path)` | 写出 EPUB 3，返回路径 |

`mimetype`、`META-INF/container.xml`、OPF、导航文档（`nav.xhtml`）都由它按规范生成，
**`mimetype` 永远是第一个条目且不压缩**；章节顺序即写入顺序，书名/作者/目录会被正确读回。

**合规性**：产物已用官方 EPUBCheck 5.3.0 按 **EPUB 3.3**（当前 W3C 推荐标准；3.4 仍为
工作草案）验证通过 —— `0 fatals / 0 errors / 0 warnings / 0 infos`。仓库里可用
`tool/validate_epub.sh` 复验（需本机有 java 与 epubcheck）。

> 想手工构建也可以：用 `zipfile` 写 EPUB 时务必保证 `mimetype` 第一个写入且
> `ZIP_STORED`（不压缩），并包含 `META-INF/container.xml` 与 OPF。

## 五、网络通讯示例（抓取来源）

```python
import json, time, requests

params = json.load(open("params.json", encoding="utf-8"))
session = requests.Session()
session.headers.update({
    "User-Agent": "Mozilla/5.0 (Linux; Android 14) AppleWebKit/537.36 Chrome/120 Safari/537.36",
    "Accept-Language": "zh-CN,zh;q=0.9",
})
if params.get("cookies"):
    session.cookies.update(params["cookies"])

def fetch(url, retries=3):
    for attempt in range(1, retries + 1):
        try:
            resp = session.get(url, timeout=(5, 20))     # 连接/读取都要设超时
            resp.raise_for_status()
            resp.encoding = resp.apparent_encoding or "utf-8"
            return resp.text
        except Exception as error:
            print(f"第 {attempt} 次失败：{error}")
            if attempt == retries:
                raise
            time.sleep(1.5 * attempt)                    # 退避重试，别把站点打挂

chapters = []
for page in range(1, int(params.get("max_pages", 3)) + 1):
    html = fetch(f"{params['urls'][0]}?page={page}")
    print(f"第 {page} 页：{len(html)} 字节")
    chapters.extend(parse(html))        # 你的解析：html.parser / 正则 / 其它纯 Python 库

from readerplus_epub import EpubBook
book = EpubBook(title=params.get("title", "未命名"), author=params.get("author", "佚名"))
for title, body in chapters:
    book.add_chapter(title, body, is_html=True)
book.save("output/book.epub")
```

要点与建议：

- 结构化接口（JSON）优先于解析 HTML，更稳也更省流量。
- 显式 `timeout`；失败重试 + 退避；不要并发几十个请求。
- 尊重站点条款与 `robots.txt`，控制频率；**只抓取可公开获取的内容**。
- 需要登录态时把 Cookie 通过插件参数传入，不要硬编码在代码里。
- 编码不确定时用 `charset-normalizer` 探测，或 `resp.apparent_encoding`。
- 只使用**纯 Python** 依赖：移动端没有 C 扩展轮子（`lxml`、`numpy` 等装不上），
  预置环境因此保持最小且各端一致。

## 六、TXT 清洗示例

```python
import json, os, re
from readerplus_epub import EpubBook

params = json.load(open("params.json", encoding="utf-8"))

# 1) 编码探测：先读字节，再决定编码
raw = open(os.path.join("input", params.get("input_file", "raw.txt")), "rb").read()
encoding = "utf-8"
for candidate in ("utf-8", "gb18030"):
    try:
        raw.decode(candidate); encoding = candidate; break
    except UnicodeDecodeError:
        continue
text = raw.decode(encoding, "replace")
print(f"{len(raw)} 字节，编码 {encoding}")

# 2) 规则清理（规则放插件参数里，不改代码就能调）
for pattern, replacement in params.get("clean_rules", []):
    text = re.sub(pattern, replacement, text, flags=re.MULTILINE)

# 3) 分章：标题正则切分，找不到就整本当一章
pattern = params.get("chapter_pattern", r"^第[一二三四五六七八九十百千0-9]+章.*$")
matches = list(re.finditer(pattern, text, re.MULTILINE))
if matches:
    chapters = [
        (m.group(0).strip(),
         text[m.end(): matches[i + 1].start() if i + 1 < len(matches) else len(text)].strip())
        for i, m in enumerate(matches)
    ]
else:
    chapters = [("正文", text)]
print(f"切分得到 {len(chapters)} 章")

# 4) 输出
book = EpubBook(title=params.get("title") or "未命名", author=params.get("author", "佚名"))
for title, body in chapters:
    book.add_chapter(title, body)
book.save(os.path.join("output", params.get("output_file", "book.epub")))
```

内置示例 `python/examples/txt_cleaner.py` 就是这一类实现，可直接改用。

## 七、编码与跨平台注意事项

| 事项 | 建议 |
|---|---|
| 文件编码 | 所有 `open()` 显式 `encoding="utf-8"`；输入先探测再解码 |
| 换行 | 统一按 `\n` 处理，写出时可用 `newline="\n"` |
| 路径拼接 | 用 `pathlib.Path("output") / "book.epub"`，不要手拼分隔符 |
| 临时文件 | 放 `work/` |
| 大小写 | 文件名、目录名全小写（部分平台区分大小写） |
| 不要用 | `subprocess`、`multiprocessing`（移动端不可用或行为异常） |
| 浮点数 | 签名/哈希场景全程用整数与字节串 |
| 依赖 | 只用纯 Python 库；预置的 `requests`、`charset-normalizer`、`readerplus_epub` 各端一致 |

## 八、调试

- `print()` 就是你的日志窗口：每阶段一行，出错时一眼看出卡在哪。
- 失败时运行页会显示异常，并给出保留的现场目录，可查看中间产物。
- 运行中可以取消；取消后不保留产物。
- 让插件尽量**幂等**：同一输入跑两次结果一致，便于重试。
- 本机试跑：接口都是「相对路径 + JSON」，在任意 Python 环境里准备一个临时目录即可复现。

## 九、常见问题

| 现象 | 处理 |
|---|---|
| 运行页只显示失败，没有细节 | 在关键步骤前后加 `print()`，并让异常往上抛 |
| 中文乱码 | 检查是否显式指定编码；用 `charset-normalizer` 探测 |
| 导入后没有目录 | 用内置 `readerplus_epub`（自动生成导航文档），或手工写带 `properties="nav"` 的 nav |
| 书架里书名是文件名 | EPUB 的 `dc:title` 为空（`EpubBook(title=...)` 一定要给） |
| 运行很久没动静 | 检查网络 `timeout` 与重试次数；必要时取消后重跑 |
| 下载被拒绝 | 补 User-Agent/Referer，降低频率；确认内容可公开获取 |
| 想用某个库但装不上 | 移动端只能纯 Python；改用标准库实现，或向应用方提需求 |

## 十、合规提醒

插件机制只提供运行环境与文件约定。请自行确保：抓取的内容可公开获取、遵守目标站点的
服务条款与 `robots.txt`、不侵犯版权、不绕过任何技术保护措施。应用不内置也不分发任何
针对特定站点的抓取脚本。

## 十一、接口速查

| 项 | 约定 |
|---|---|
| 读参数 | `params.json`（UTF-8；缺失字段给默认值） |
| 读输入 | `input/<input_file>` |
| 写产物 | `output/*.epub`（EPUB 3，用 `readerplus_epub` 生成即合规） |
| 临时文件 | `work/`（运行结束清理） |
| 日志 | `print()` → 运行页实时显示 |
| 成功/失败 | 正常结束＝成功；抛异常＝失败并显示原因与现场 |
| 预置依赖 | `requests`、`charset-normalizer`、`readerplus_epub`（各平台一致） |
