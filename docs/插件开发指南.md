# 插件开发指南（JS 风味脚本 + EZBK）

> 对应重构后的脚本体系：**纯 Dart 的 JavaScript（ES5 子集）解释器**，
> 书籍格式为 **EZBK**（简单电子书）。旧 Hetu 脚本（`.ht`）与旧 API 已不再使用。

## 一、总览

| 项 | 说明 |
|---|---|
| 语言 | JavaScript（ES5 子集，见第六节） |
| 执行 | 独立 isolate；到点 `Isolate.kill`，**真取消** |
| 文件扩展名 | `.js` |
| 沙箱 | 只能调用本文列出的宿主能力；无文件系统、无进程、无 `eval` |
| 存储 | 三级：`mem`（内存）/ `tmp`（临时）/ `perm`（永久），点分命名 |
| 任务信息 | 脚本从 `tmp.read.utf8('task')` **主动读取** |

## 二、最小示例

```js
var task = JSON.parse(tmp.read.utf8('task'));
log('任务：' + task.task + '，参数：' + JSON.stringify(task.params));

var resp = http.get('https://example.com/api?q=' + task.params.q);
if (resp.status !== 200) {
  result('请求失败：' + resp.status);
}
result(resp.text);
```

## 三、任务信息

宿主在运行开始时把任务信息写入**临时层**保留键 `task`（JSON 文本）：

```js
var task = JSON.parse(tmp.read.utf8('task'));
// task.kind     : 'source' | 'clean' | 'tool' | 'import'
// task.task     : 'search' | 'download' | 'import' …
// task.params   : { 键: 字符串 }
// task.inputs   : [{ name, size }]
// task.outputDir: 产物目录（仅提示用途）
```

输入文件以**原始字节**放在 `input/<name>`：

```js
var bytes = tmp.read.raw('input/book.txt');
var text = decode(bytes, 'auto');
```

保留键 `task`、`input/*` **不可写**，写入会报错。

## 四、三级存储（点分命名）

三级用法完全同构：

```js
mem.read.raw(k)     mem.read.utf8(k)
mem.write.raw(k,b)  mem.write.utf8(k,s)
mem.remove(k)       mem.keys()        mem.clear()
// tmp.*、perm.* 同名同义
```

| 层 | 后端 | 生命周期 | 配额 |
|---|---|---|---|
| `mem` | 内存 | 本次运行，结束释放 | 50 MB |
| `tmp` | 磁盘 | 本次运行，结束清除 | 100 MB |
| `perm` | 磁盘 | 永久，用户可在「脚本 → 存储」查看/编辑/清除 | 50 MB |

```js
var cursor = perm.read.utf8('cursor') || '1';
perm.write.utf8('cursor', String(Number(cursor) + 1));
tmp.write.raw('page2.html', http.get(url).bytes);
```

约定：键为 UTF-8 文本；值为字节；`write.raw` 收字节、`write.utf8` 收字符串（传错报错）；
`read` 不存在返回 `null`；超配额抛错。

## 五、宿主能力

### 5.1 日志与结果

| 函数 | 说明 |
|---|---|
| `log(...args)` | 实时回传界面（不显示进度条） |
| `result(value)` | 返回任务结果；字符串或可序列化对象 |

### 5.2 网络

```js
http.get(url)                 // → { status, headers, text, bytes }
http.post(url, body)          // → 同上
http.request({
  url: '…',
  method: 'POST',
  headers: { 'User-Agent': '…' },
  body: '…',
  wantBytes: true,            // text 为空，bytes 为原始字节
  timeoutMs: 20000,
})
```

- 失败**不中断脚本**：降级为 `status: 0` + `error` 字段；
- 中文站点请用 `decode(bytes, encoding)` 自行处理编码。

### 5.3 编码与工具

| 函数 | 说明 |
|---|---|
| `decode(bytes, encoding?)` | 字节 → 文本（省略 encoding 为自动 UTF-8） |
| `urlJoin(base, relative)` | 拼接 URL |
| `base64.encode/decode` | Base64 |
| `hex.encode/decode` | 十六进制 |

### 5.4 加解密

```js
digest('md5' | 'sha1' | 'sha256', input, encoding?)
hmac('sha256', key, input, encoding?)
```

### 5.5 询问用户

```js
var answer = ask('请输入验证码', { secret: true, preset: '' });
```

- 无界面时返回空字符串；秘密内容不写入日志；单次运行有提问次数上限。

### 5.6 内建对象

`JSON.parse/stringify`、`Math.*`、`parseInt`、`parseFloat`、`String/Number/Boolean`、
`Object.keys/values`、`Array.isArray`，以及字符串/数组常用方法。

## 六、支持与不支持

**支持**：`var/let/const`、`if/else`、`while`、`do-while`、`for`、`for-in/of`、
`function`、递归、闭包、`try/catch/finally`、`throw`、三元、逻辑短路、
`===`/`!==`、数组/对象字面量、成员与下标访问。

**不支持（解析期报错）**：`class`、`import/export`、`async/await`、`yield`、
解构、展开运算符、`eval`、`new Function`（沙箱要求）。

## 七、脚本接管导入

导入电子书时可选择「用脚本导入」：宿主把**文件原始字节**放进 `input/<name>`，
脚本处理后用 `result()` 返回 **EZBK 文本**，宿主据此建书。

```js
var task = JSON.parse(tmp.read.utf8('task'));
var name = task.inputs[0].name;
var text = decode(tmp.read.raw('input/' + name), 'auto');
var out = '# ' + name + '\n' + text;
result(out);
```

返回内容须符合 `docs/ezbk-format-v1.1.md`：`#` 三级标题、单独一行 `---` 换页、
`\\` 开头为转义行、`@` 为单行命令。

## 八、脚本类型声明

```js
// @script kind=source name="我的书源"
```

| kind | 出现位置 |
|---|---|
| `source` | 书源页（搜索/下载） |
| `clean` | 清洗脚本 |
| `tool` | 其它工具（**默认**） |

## 九、安全说明

1. **无文件系统**：只能通过三级存储读写数据；
2. **无进程/无原生调用**：`eval`、`Function` 构造被拒绝；
3. **体积受限**：`mem` 50MB、`tmp` 100MB、`perm` 50MB；
4. **可强制终止**：死循环会被硬超时杀掉，应用不受影响；
5. **临时数据自动清理**：`tmp` 在运行结束与应用启动时清空。

## 十、调试建议

- 用 `log()` 输出中间值，界面实时可见；
- 网络问题先打印 `resp.status` 与 `resp.headers`；
- 状态类数据放 `perm`，页面缓存放 `tmp`，热数据放 `mem`；
- 「脚本 → 存储」可查看/编辑永久存储：文本直接编辑，二进制显示 `(raw)`。
