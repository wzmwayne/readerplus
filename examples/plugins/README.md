# 示例脚本（Examples）

本目录存放**示例脚本**，仅用于学习脚本写法与本地自测。应用**不再内置任何脚本**，
安装包里不含这里的文件，运行时也不会自动安装。

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `fake_source.js` | 书源示例 | 不联网的假数据书源，用于验证搜索/下载流程 |
| `gutenberg_source.js` | 书源示例 | 演示从公开站点抓取的书源写法 |
| `txt_cleaner.js` | 清洗示例 | 演示把任意文本规范化并输出 **EZBK** 文本 |

## 如何导入

1. 打开应用底部「**插件**」页；
2. 点右上角的导入按钮（接受 `.js` 脚本与 `.json` 规则）；
3. 选择本目录下的 `.js` 文件，确认导入后即可在书源/清洗列表中使用。

也可以在「插件」页的模板基础上自行编写脚本；导入的脚本只保存在本机。
